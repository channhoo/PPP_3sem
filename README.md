## Описание проекта

Программа визуализирует аттрактор Лоренца — численное решение системы дифференциальных уравнений методом Эйлера. Точка движется по аттрактору и оставляет след в проекции XY; форма следа — характерная «восьмёрка» (бабочка) Лоренца. Реализована интерактивная регулировка параметров системы (sigma, r, b) и скорости анимации с помощью слайдеров.

## Функциональные возможности

### Основной функционал:

- численное интегрирование системы Лоренца методом Эйлера;
- отрисовка следа точки на холсте tkinter;
- интерактивные слайдеры параметров sigma, r, b;
- регулировка скорости анимации (число шагов за кадр);
- цветной след, зависящий от координаты z.

### Дополнительный функционал:

- пауза и продолжение по клавише Space;
- сброс модели в начальное положение по клавише R;
- очистка холста без сброса модели;
- метка статуса (Running / Paused).

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/channhoo/PPP_3sem.git
cd PPP_3sem
```

### 2. Создание и активация виртуального окружения

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск программы

```bash
python main.py
```

### 5. Управление

- слайдеры sigma, r, b — регулировка параметров системы в реальном времени;
- слайдер speed — скорость анимации (шагов за кадр);
- Space — пауза и продолжение;
- R — сброс модели в начальное положение и очистка холста;
- Clear — очистка холста без сброса модели.

```
│       └── controls.py
├── tests/
│   ├── __init__.py
│   └── test_model.py
└── venv/
```

Назначение основных модулей:

- main.py — точка входа в программу;
- src/app.py — класс App: окно, холст, главный цикл анимации;
- src/models/lorenz_model.py — модель Лоренца: численное интегрирование системы уравнений;
- src/renderers/renderer.py — рендерер: перевод координат модели в экранные и отрисовка следа;
- src/widgets/controls.py — панель управления: слайдеры и кнопки;
- tests/test_model.py — тесты модели.

Обоснование структуры: проект разделён на слои по принципу разделения ответственности. Модель (models) содержит только математику и не зависит от tkinter, что упрощает тестирование. Рендерер (renderers) отвечает только за отрисовку и не знает о физике процесса. Виджеты (widgets) изолируют элементы интерфейса. Такое разделение упрощает тестирование, модификацию и повторное использование кода.

## Пример использования

Запуск программы:

```bash
python main.py
```

Откроется окно с чёрным холстом и панелью управления. Через несколько секунд на холсте появится характерная «бабочка» Лоренца. При изменении слайдера r форма аттрактора меняется. Клавиша Space ставит анимацию на паузу, клавиша R выполняет сброс.
